# 📱 UrbanMall Expo Go Mobile Shell

This directory contains a complete, production-ready React Native Expo shell configured to load your beautiful UrbanMall application natively on an iPhone or Android device using **Expo Go**.

---

## 🚀 Langkah-Langkah Preview (Bahasa Indonesia)

### 1. Persiapan Perangkat HP Anda
*   **Android:** Download aplikasi **Expo Go** dari Google Play Store.
*   **iOS (iPhone):** Download aplikasi **Expo Go** dari Apple App Store.

### 2. Install Dependensi di Komputer
Buka terminal baru di direktori ini (`/mobile`) dan jalankan:
```bash
cd mobile
npm install
```

### 3. Jalankan Expo Development Server
Jalankan perintah berikut untuk menginisialisasi server lokal dan membuat QR Code:
```bash
npm start
```
Terminal Anda akan menampilkan sebuah **QR Code** besar yang interaktif.

### 4. Scan QR Code untuk Memulai Preview
*   **Android:** Buka aplikasi **Expo Go** di HP Anda, ketuk **"Scan QR Code"**, lalu arahkan kamera HP ke QR Code yang ada di terminal komputer Anda.
*   **iOS (iPhone):** Buka aplikasi **Kamera bawaan iPhone** Anda, arahkan ke QR Code di terminal, ketuk tautan kuning bergaya Expo untuk membuka **Expo Go**.

Aplikasi UrbanMall Anda akan dimuat secara instan di HP Anda dengan nuansa fully native!

---

## 🚀 Steps to Preview (English)

### 1. Prepare Your Mobile Device
*   **Android:** Install the **Expo Go** app from the Google Play Store.
*   **iOS (iPhone):** Install the **Expo Go** app from the Apple App Store.

### 2. Install Project Dependencies
Open your terminal inside this `/mobile` folder and execute:
```bash
cd mobile
npm install
```

### 3. Spin Up the Expo Server
Start the development script to generate the console QR Code:
```bash
npm start
```

### 4. Scan the QR Code to Run
*   **Android:** Load the **Expo Go** application on your smartphone, tap **"Scan QR Code"**, and scan the QR displayed in your terminal.
*   **iOS (iPhone):** Launch the **native iOS Camera**, point it at the terminal QR code, and click the yellow Safari prompt to boot the application inside **Expo Go**.

Now you can click buttons, test checkout, map locations, and interact with the Gemini AI assistant directly in your palm!
